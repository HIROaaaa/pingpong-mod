## 3. 明天**不要**踩的坑（都是这几次真实踩过的）

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 改现有工程的 `gradle.properties` 去试 1.16.5 | 会把能用的 1.20.1 构建搞坏 | 1.16.5 用独立探针工程 `F:\project\pingpong-mod-1165` |
| 用 PowerShell 的 `Set-Content -Encoding UTF8` 改 `.js` | 加 BOM → Node 解析 shebang 报语法错 | 用 node 的 `fs.writeFileSync` 改 |
| 改 `.js` 里的函数前不读全文 | `function` 重定义不报错、后者静默覆盖前者 | 先完整读文件，改完 `grep "^function 名字"` 确认只有一处 |
| 断言里用循环残留变量当被测值 | 测试"永远通过"，其实是假的 | 从结果数组取值，期望与实际都打印 |
| 指望 `gradlew` 自己下 Gradle 分发包 | Java 走 Steam++ 代理报 `PKIX path building failed` | 用 PowerShell/`HttpWebRequest` 下，大文件用 `AddRange` 续传 |
| 网络超时后以为彻底坏了 | 白等或者放弃 | 这几个服务时通时不通，**重试通常就行**（push 失败两次后成功过） |
